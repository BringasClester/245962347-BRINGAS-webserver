1. The `CREATE DATABASE` command is used to create a new database.
2. The `USE` command is used to select and switch to the database you want to work in.
3. The `SHOW TABLES;` command is used to display all the tables in the current database.
4. The `INSERT INTO` command is used to add new records into a table.
5. The `SELECT` command is used to retrieve records from a table.
6. A primary key uniquely identifies each row in a table to ensure there are no duplicate or empty ID values.
7. Auto_increment automatically generates the next sequential number for a column every time a new row is added.
8. Update changes data that is already inside a table, while delete completely removes rows from it.
